# 📊 Sales Analytics Dashboard (แดชบอร์ดวิเคราะห์ยอดขาย)

ระบบแดชบอร์ดวิเคราะห์ยอดขายจากไฟล์ `sales_data.csv` พร้อมระบบทำความสะอาดข้อมูล (Data Cleaning) อัตโนมัติ แสดงผลสรุปสถิติ กราฟ และตารางแบบ Interactive ในหน้าเดียว

🌐 **Live Demo (GitHub Pages):** [https://koooooooorrrrr.github.io/sales-dashboard/](https://koooooooorrrrr.github.io/sales-dashboard/)

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

### 1. 🧹 ระบบทำความสะอาดข้อมูล (Data Cleaning System)
- **ทำความสะอาดข้อความพื้นฐาน**: ตัดช่องว่างหน้า-หลัง (Trim) และอักขระขึ้นบรรทัดใหม่ทุกคอลัมน์
- **คัดกรองข้อมูลขยะและบันทึกเหตุผลรายแถว (5 หมวดเกณฑ์)**:
  1. **อายุผิดปกติ**: ค่าว่าง, ไม่ใช่ตัวเลข, ค่าน้อยกว่า 1 ปี ($\le 0$) หรือมากกว่า 120 ปี ($> 120$) (เก็บเฉพาะช่วง 1 - 120 ปี)
  2. **รหัสและวันที่/เวลาไม่ถูกต้อง**: รหัสคำสั่งซื้อ (`ORD######`) หรือรหัสลูกค้า (`C#####`) ผิดรูปแบบ, วันที่ผิดรูปแบบ, เวลาไม่อยู่ในช่วง 00:00-23:59, วันจัดส่งติดลบ
  3. **ตัวเลขและการคำนวณยอดเงินผิดปกติ**: ราคา, จำนวน, ยอดก่อนค่าส่ง หรือยอดสุทธิ $\le 0$; ส่วนลด(%) นอกช่วง 0-100%; ค่าจัดส่งติดลบ; คะแนนรีวิวนอกช่วง 1-5; ยอดรวมสุทธิไม่สอดคล้องกับสูตรคำนวณ (คลาดเคลื่อนเกิน 0.05)
  4. **หมวดหมู่และภูมิศาสตร์ขัดแย้ง**: เพศไม่ใช่ "ชาย" หรือ "หญิง" (เช่น พบเพศ "ไม่ระบุ"), สถานะ/หมวดสินค้า/ช่องทาง/วิธีชำระเงินไม่อยู่ในรายการที่ถูกต้อง, ภาคไม่ตรงกับจังหวัด
  5. **ข้อมูลซ้ำ (Duplicates)**: รหัสคำสั่งซื้อซ้ำ หรือข้อมูลสำคัญซ้ำกันทั้งหมด
- **การจัดการคะแนนรีวิว**: แถวที่ไม่มีคะแนนรีวิวจะไม่ถูกลบ แต่จะข้ามค่าว่างตอนคำนวณค่าเฉลี่ย
- **รายงานสรุป & Modal ตรวจสอบ**: แสดงตัวเลขจำนวนข้อมูลดิบ, ข้อมูลสะอาด, ข้อมูลที่ตัดออกแยกตามหมวด และมีปุ่มเปิดดูรายการข้อมูลขยะพร้อมเหตุผลทุกแถว

### 2. 🔍 ตัวกรองแบบ Real-time (Interactive Filters)
- กรองสถานะคำสั่งซื้อ (เริ่มต้น: สำเร็จ, เลือกดู ยกเลิก / คืนสินค้า เพิ่มได้)
- กรองช่วงอายุ (ต่ำสุด - สูงสุด)
- กรองเพศ (ทั้งหมด / หญิง / ชาย)
- กรองภาคและจังหวัด (มีระบบ Cascading เลือกภาคแล้วตัวเลือกจังหวัดจะปรับตาม)
- กรองหมวดหมู่สินค้า, ช่องทางการขาย, วิธีชำระเงิน
- ปุ่มรีเซ็ตตัวกรองทั้งหมด
- ปุ่มส่งออกข้อมูลที่คลีนแล้วเป็นไฟล์ `.csv` (รองรับภาษาไทยใน Excel ด้วย UTF-8 BOM)

### 3. 📈 การ์ดสรุป KPI & กราฟ & ตาราง
- **การ์ดสรุป KPI**: จำนวนลูกค้าไม่ซ้ำ (ระบุชัดเจนว่าผู้หญิงกี่คน / ผู้ชายกี่คน), จำนวนออเดอร์, ยอดขายสุทธิ, ส่วนลดรวม, อายุเฉลี่ย, วันจัดส่งเฉลี่ย, คะแนนรีวิวเฉลี่ย
- **กราฟวิเคราะห์ (Chart.js)**:
  - 📅 แนวโน้มยอดขายตามวันที่ / รายเดือน
  - ⚥ สัดส่วนลูกค้า หญิง vs ชาย
  - 📦 ยอดขายตามหมวดหมู่สินค้า
  - 🗺️ ยอดขายตามภูมิภาค
  - 📡 ยอดขายตามช่องทางการขาย
  - 🏙️ Top 10 จังหวัดยอดขายสูงสุด
  - 💳 ยอดขายตามวิธีชำระเงิน
- **ตารางรายการคำสั่งซื้อ**: ค้นหาด่วน (Instant Search), จัดเรียงคอลัมน์ (Sort), และแบ่งหน้า (Pagination)
